# ⚡ GEEKCORE BRUTALIZER ULTIMATE



A simple browser extension (Manifest V3) which takes off all corporate roundishness, softness, and shadows, turning websites into brutal, sharp, terminal-like environments from the 2007 hacker era.

## 🛠️ FEATURES
* **Global Brutalism:** Forces pixel-perfect `JetBrains Mono` font and sharp square corners across the entire web.
* **CRT Screen Matrix:** Lays down an authentic old-school CRT monitor scanline grid overlay.
* **Arasaka HUD Mode:** Enforces a deep, glitch-aesthetic dark mode with translucent burgundy borders and sharp structural left-accent lines for **GitHub** and **Wikipedia**.
* **Icon Isolation:** Preserves standard system icon glyphs and arrow sets (like FontAwesome) without breaking them.

## 🚀 INSTALLATION

### For Chromium-based browsers (Chrome, Edge, Opera, Yandex, Brave):
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Open your browser and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click the **Load unpacked** button in the top-left and select the extension folder.
5. Reload your active tabs using `Cmd + R` (`Ctrl + R`).

### For Firefox users:
1. Open Firefox and type `about:debugging` into the address bar.
2. Click on **This Firefox** in the left sidebar.
3. Click the **Load Temporary Add-on...** button.
4. Select the `manifest.json` file inside the extension folder.
